# 配方：道具与图标

## 场景道具（门、柜子、告示板、窗、钟……）

道具在游戏里通常按原始像素显示，不缩放，所以 **交付尺寸必须和规格完全一致**。

1. 尺寸：生成比例与规格一致、约 3–4 倍大小，宽高取 32 的倍数，例如 170×290 → `576x992`（比例 0.58）。
2. 视角：横版场景里的墙面道具（门、窗、柜子、告示牌）用**严格正交**的正面视图，提示词写“正交视图，边框是标准矩形，上下边水平，左右边垂直，没有透视和倾斜”。模型仍常画成上窄下宽的仰视透视，自查时要特别看外框四边；有透视就用 `sprite_tools.py rectify` 校正（见第 5 步）。地面道具用略带俯视的侧面。
3. 提示词：只写物体本身，加上 `纯白色背景，无阴影，平光，无文字，无水印`。需要字时（门牌、标志）先看规格：如果文字由代码绘制，就必须留空。
4. 多个道具共用一个会话（例如 “Agent · classroom 墙面道具”），每个道具一轮，每轮 2–4 张。可以开一个关卡请用户“每个道具各选一张”（`--min N --max N`），提交后按 `message_id` 对应到各个道具。
5. 后处理：
   - 不透明的长方形道具（门、柜子）：`fit --box 170x290 --mode cover`（铺满后居中裁切）。如果规格要求不透明，交付前用 `flatten`。
   - 带透明轮廓的道具：先抠图（`cutout_compare.py`，见 alpha-and-cleanup.md），再 `fit --box WxH --mode contain --anchor bottom`。
   - 外框带透视的平面物体：抠图后先 `rectify`（按 alpha 外轮廓的四个角做透视校正，拉成矩形；轮廓不规则时用 `--corners` 手动给四个角），再 `fit`。classroom 的窗户就是这样修正的。
6. 一致性：同一场景的道具，缩放倍数要接近（生成尺寸 ÷ 交付尺寸），线宽才会统一；交付前把几件道具放进同一张 `mock` 预览，一起确认。
7. 自发光部分（例如出口指示牌、灯管）按“自己发光”的样子画，饱和、明亮；前景剪影（柱子、椅子）保持接近纯黑。

## 物品图标（例如 64×64）

1. 生成 `1024x1024`，提示词写“单个物品，居中，正面或 3/4 视角，轮廓清晰，纯白色背景，无阴影”。
2. 抠图（`cutout_compare.py`）→ `fit --box 64x64 --mode contain --anchor center`。如果轮廓太细，先 `trim --pad 16` 再缩放。
3. 缩到 64 px 后必须一眼认得出：剪影鲜明、主色清楚；细节太多就请用户选更简洁的候选，或者把提示词改成“简洁的剪影、少量细节”。
4. 图标通常同时用在场景（地上的拾取物，会被光照压暗）和 HUD（全亮）。`mock` 预览两种情况都要放。

## 检查清单

- [ ] 尺寸与规格完全一致；透明或不透明与规格一致。
- [ ] 没有阴影、光斑、文字（除非规格要求）。
- [ ] 与同场景其他道具的线宽、配色、明度协调。
- [ ] 交互提示的位置等和道具高度相关的代码常量：尺寸不变就不用改；变了要一起改（见 phaser-delivery.md）。
