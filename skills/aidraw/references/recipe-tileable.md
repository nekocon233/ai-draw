# 配方：横向可平铺的墙、地、天花板

这类贴图在游戏里横向重复铺满，所以 **高度必须精确，左右必须无缝**。规格里如果有 `bands`（例如墙裙、踢脚线所在的行），这些水平线还要对齐。

## 步骤

下面的 `$S` 指 `<技能目录>/scripts/sprite_tools.py`。

1. **尺寸**：高度取交付高度的整数倍 k（通常 k=2），宽度至少是 k ×（交付宽度 + 融合宽度）。例如交付 1024×410、融合 96，k=2 → `2304x832`（宽高都要是 32 的倍数；生成后再精确缩放到 410 高）。
2. **构图控制**：把现有占位图作为参考图 1，用 `--preset pose_composition`，让模型沿用色带的位置和比例，外观和材质按描述重画：

   ```bash
   aidraw gen --session S --ref public/assets/env/env_wall.png --preset pose_composition --size 2304x832 --count 3 \
     --prompt "夜间教室走廊的墙面，正面平视的连续墙面，上部是旧白灰泥墙（有细小裂纹、斑驳），中部一条深色木腰线，
   下部是青灰色墙裙，最下方是深色踢脚线。左右两端内容连续、可以横向平铺，没有门窗、没有物体、没有文字。
   平光，无阴影，无光斑，无暗角。<style.md 的风格描述>"
   ```

   如果构图不听话，就不用预设，直接在提示词里写每条色带从上往下占多少比例。
3. **对齐检查**：缩放到交付高度后，用 `sprite_tools.py guides <图> --at 286,296,395 -o guides.png` 画出规格要求的水平线，看色带是否落在线上。偏差在 2–3 px 以内可以接受；偏差大就重出，或者对色带区域分段裁切、拉伸后再拼接（要说明给用户）。
4. **无缝**：

   ```bash
   python3 $S tile-x scaled.png -o tile.png --width 1024 --height 410 --blend 96 --opaque
   python3 $S seam-check tile.png -o tile_x3.png --mark
   ```

   `seam_score_x` 应 ≤ 1.8；预览图横向重复了 3 次，看接缝处有没有跳变或重复的特征（同一块污渍在每个周期都出现会很假，可以请用户在网页里编辑掉，或者重新生成）。
5. **自查**：平铺 3 次的预览、带参考线的图和 `mock` 只用来自查，结论在对话里报告（附本地路径）。
6. **交付**：墙、地、天花板通常不透明（`--opaque` 输出 RGB）。高度必须和规格完全一致，因为游戏按 1:1 铺贴。
7. **发素材、开交付后关卡**：
   - `aidraw post` 发平铺好的贴图本身，说明写在同一条帖子里：尺寸、接缝分数、和上一版的区别。
   - 然后开 `--min 0 --max 1` 的交付后关卡。接缝在游戏里看得最清楚，提醒用户去项目预览里看。

## 注意

- 不画光照：灯管投在墙上、地上的光斑由游戏实时画；贴图里只保留轻微的环境遮蔽（墙角、接缝处略暗）。
- 地面贴图中“脚踩的那一行”如果在规格里有标注，务必保持在原来的位置。
- 天花板、墙、地面三张要放在一起看一次（`mock --bg` 用拼起来的整面墙），确认明度和配色协调。
