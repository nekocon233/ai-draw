# 工作流、LoRA 与提示词

## 工作流怎么选

| 工作流 | 用途 | 关键限制 | 耗时 |
|---|---|---|---|
| `qwen_image_21_t2i` | 文生图，可叠 LoRA | 宽高是 32 的倍数，256–3072，总像素不超过 3072×1536；每批 1–16 张 | 1024² 约 55 秒一张（40 步） |
| `qwen_image_21_i2i` | 参考图编辑或参考生成，1–3 张参考图，可叠 LoRA | 参考图 1 是编辑目标；`qwen_reference_resolution` 512–2048 | 1024 约 66 秒，1536 约 156 秒 |
| `gpt_image` | GPT Image 编辑与合成，最多 16 张参考图 | 输出固定 1254×1254，不支持种子、尺寸、LoRA；用的是 Codex 订阅额度 | 16–23 秒 |
| `minimax_h3` / `minimax_h3_ref` / `minimax_h3_face` | 视频（首帧驱动 / 指定首尾过渡 / 动作参考 / 换脸） | 循环素材默认只给首帧；动作参考与换脸暂在网页使用 | 8–16 分钟 |

经验：

- 风格和一致性靠 Qwen 加 LoRA，加上固定种子和参考图。
- 改视角、改姿势、重构图这类大改动，GPT Image 往往更听话；但它没有 LoRA，画风要再用 Qwen 参考图生图统一回来。
- Qwen 一次生成多张时，每张都是独立任务，顺序执行。

## 提示词

- Qwen 接受中文自然语言。写清主体、视角、全身/半身、背景、构图，不要只堆标签。
- 引用参考图用 `<image1>`、`<image2>` 或 `@图片1`；引用的序号必须真的有那张参考图，否则返回 422。
- 游戏素材统一加上：`纯白色背景，无阴影，无地面，平光，无文字，无水印`。横版游戏的平面道具再加 `严格正交的正面视图，边框横平竖直，没有透视`。需要透明时再加 `RGBA 透明背景`，但 Qwen 的原生透明不可靠，一律按需要抠图来规划。
- 风格词交给 LoRA 和 `art/style.md` 里定下的描述，不要每次即兴改风格词。
- Sen 等 LoRA 偶尔会画出乱码文字，提示词里写明“无文字”，自查时也重点看。

## LoRA

用 `aidraw loras` 查看当前已安装、可用的 LoRA；`--lora 名称[:强度]`，强度 0–1，默认 0.8，可以叠加多个。只有 Qwen 工作流支持 LoRA，而且都不需要触发词。

| LoRA | 特点 |
|---|---|
| Ameniwa | 粗线条、平涂；提示词里需要写动漫画风相关的描述 |
| Sen | 粗墨线、明亮平涂；偶尔漏出像水印的乱码文字 |
| Daikei | 不带固定画风的 v2；偏向黑发和红色；0.8 大致相当于 v1 的 1.0 |
| CZN | Q 版战斗小人；0.8 时个别种子会退回正常比例或写实 |
| Darkest Dungeon | 全身侧视的哥特风战斗角色（以女性为主）；写完整角色描述，1024²，0.8；透明素材要另行抠图 |

**风格定调方法**：固定描述和种子，分别用无 LoRA 以及 2–3 个候选 LoRA（各 0.6 和 0.8）各出 1–2 张，放进同一个会话，开一个关卡请用户选。选定后写进 `art/style.md`，后续沿用，不要中途更换。

## 预设（`--preset`）

| ID | 作用 | 游戏素材里怎么用 |
|---|---|---|
| `pose` | 参考图 1 提供角色、画风、背景，参考图 2 提供动作和姿态 | 同一角色换姿势、换朝向（参考图 2 用姿势参考） |
| `pose_composition` | 只取参考图 1 的姿势、构图、镜头和比例；外观按描述画，画风由 LoRA 决定 | 用占位图或草图控制构图，例如墙的色带位置、道具外形 |
| `sketch_finish` | 草稿成品化，要求明暗和接触阴影、纯色背景 | **不要用于游戏素材**：会画进阴影 |

视频预设属于第二阶段。

## 种子与复现

- `--seed N` 固定种子；第 n 张用 N+n−1。结果 JSON 和网页上都会显示每张图的种子。
- 想在选中的图上做小改动：同种子、同参数，只改提示词里的一处细节；或者把选中的图作为参考图 1 做编辑。
- 种子要和工作流、尺寸、LoRA、步数一起记录（`--job` 会自动写进任务日志）。
