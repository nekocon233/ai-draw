# 审核关卡

关卡是 agent 在会话里提出的一个问题。用户在网页里给结果点「选用」（本会话任何一轮都能选，包括他自己画的），可以写补充说明，然后点「提交给 Agent」或「都不满意，重来」。手机上审核条默认折叠成一行，点开即可操作；如果用户正在看别的会话，网页会弹通知，带「前往」按钮。

## 什么时候开

| 颗粒度 | 关卡 |
|---|---|
| `auto` | 只在交付后开一个可选关卡（`--min 0 --max 1`） |
| `key` | 风格定调（选 1）→ 候选（选 1 或几张）→ 交付后可选关卡 |
| `every` | 每次生成或处理后都开 |

三种关卡：

- **挑候选**：`--max 1`，或者 `--min 1 --max 3`。
- **交付后可选关卡**：`--min 0 --max 1`。成品已经放进项目，也发了素材帖。用户可以：
  - 不选直接提交，表示满意；
  - 选用自己在网页里编辑的结果（编辑帧导出、编辑后的图）再提交，表示按他的编辑交付；
  - 点「都不满意，重来」。
- **只需确认**：`--max 0`，只有“通过”和“重来”。用于不涉及挑图的确认。

一个会话同时只能有一个打开的关卡。开新关卡前要么等上一个结束，要么加 `--replace`（会撤销旧的），不要叠着问。

## 怎么问

问题要具体，写清楚选几个、看什么：

- 风格：`选一种你喜欢的画风（每组左边 0.6、右边 0.8）。主要看线条和配色，不用在意姿势。`
- 候选：`选一张作为侧视基准图：朝右、全身、脚完整、衣服和原型一致。都不行就点“重来”并写哪里不对。`
- 多选：`--min 1 --max 3`，问题里说明“选 1–3 张，后面会从中细化”。
- 交付后：`--min 0 --max 1`，问题模板：

  > 待机动画已放进游戏（上面那条：22 帧，每秒 8 帧）。满意就直接点「提交给 Agent」（选用上面那条再提交也一样）；想换另一段视频，就选用那段视频再提交；想自己改，在视频那一轮点「编辑帧」，改完导出精灵图，选用导出的图再提交；想重新生成就点「都不满意，重来」并写意见。

- 只需确认：`--max 0`，问题写“没问题点通过；有问题点重来并写意见”。

问题里只写要用户做什么、看什么，不写过程说明，也不提游戏截图（这些在对话里说）。

开关卡后在对话里告诉用户：会话链接、要做什么、可以在同一会话里自己改提示词重画或编辑。

## 怎么等

- **Claude Code**：把 `aidraw gate wait <id> --timeout 3600 --download <目录>` 放到后台运行（`run_in_background`）。用户提交后命令结束，agent 会被唤醒并继续。
  - 后台任务最长 2 小时。超时（退出码 2）后重新跑一次接着等，不要重开关卡。
  - 不要用 `nohup`、`setsid` 这类脱离会话的进程等关卡：进程结束时不会唤醒 agent，用户点了「重来」也没人处理。
- **其他 agent**：请用户在网页里提交后回到对话说一声，再运行 `aidraw gate wait <id> --timeout 5`。
- 默认 `--timeout 540`；超时返回退出码 2，用输出里的 `resume` 命令接着等，不要重开关卡。

**会话里的问答气泡**：后端自动生成，agent 不用另外发帖。

- 开关卡时，左侧留下 Agent 的提问气泡；关卡结束后标成“已回答”或“已撤销：原因”。
- 用户提交时，右侧留下他的回答气泡：选了哪些（带缩略图）、“满意，直接提交”，或“都不满意，重来：意见”。
- `gate wait` 读到回答（或 agent 用 `gate submit` 替用户记下回答）时，自动调用 `POST /api/agent/gates/<id>/ack`，回答气泡显示“Agent 已收到”。
- 如果一直显示“等待 Agent 读取”，说明没有 agent 在等，用户会回对话里叫你。

## 处理结果

- `approve`：`picks` 就是选中的结果，带 `message_id`、`image_index` 和 `seed`。下载到 `--download` 目录后继续。如果选的是用户自己生成的图，同样照用；它的参数可以用 `aidraw round get` 查。
  - 交付后关卡里的选择，按 `gate wait --job` 给选中项标的 `by` 和 `source` 处理：
    - `picks` 为空，或者选的是 agent 发的成品帖（`by=agent, source=post`）：用户满意，结束这一项（项目验收照项目规则）。
    - 选的是另一段生成的视频或另一张生成的图（`by=agent, source=gen`）：换用它重新交付。
    - 选的是用户的编辑结果（`by=user`，例如 `/uploads/spritesheet/…`、编辑后的图）：按 SKILL.md 第 6 节的人工编辑流程交付。
    - 后两种交付完都要再发素材、再开交付后关卡。
- `redo`：读 `note`（以及可能附带的 picks，表示“接近但不够”的图），说明你理解的改动，再生成新一批。
- `cancelled`：关卡被撤销（被新关卡替换，或会话被删）。问用户怎么继续。
- 用户在对话里回答：用 `aidraw gate submit <id> --decision approve --pick <url> --note "用户在对话里说：…"` 把他明确说的选择记下来；含糊时先确认，不要猜。也可以 `aidraw gate cancel <id> --reason "已在对话里确认"`。

## 记录

所有关卡带 `--job art/jobs/<job>.jsonl --step <步骤>`，问题、选择和意见都会写进日志。下次接手时用 `aidraw job show` 查看已经定下的事，不要重复问用户。
