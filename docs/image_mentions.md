# 参考图引用

Qwen-Image-2.1 和 GPT Image 的聊天输入框、历史编辑框支持输入 `@`，从该输入框当前的参考图中选择图片。列表最多三张，编号与参考图顺序一致；历史生成结果须先通过现有操作添加为参考图。

- 选择后插入 `@图片1` 等文字，重复引用不会新增图片或改变顺序。
- 方向键选择，Enter 确认，Esc 关闭；Shift+Enter 换行，中文输入法确认不会发送。
- 删除参考图时同时调整剩余图片和提示词编号。被删除图片的引用变为 `@图片已移除`，必须重新选择或删除此标记才能发送；重新添加图片不会复活该标记。
- 更换图片保留所在位置及其引用编号。历史编辑中的更改在取消后丢弃。
- 草稿和历史保存原始引用文字及对应参考图，沿用现有会话、消息字段。
- 引用必须写成 `@图片1`，中间不能有空格；`@图片 1` 不会被识别，会原样作为文字发给模型。
- 加号菜单中的预设也可以包含引用。选中的预设显示在输入框上方，不写进输入框；预设需要的参考图按引用编号和预设声明的参考图数量计算。当前工作流不支持引用时预设不可选；缺图时仍可先选，标签上会提示，发送时拦截并说明先添加哪一张图。
- 「扩写助手」仅扩写文字；扩写前和应用结果时均校验 `@图片N` 引用，缺失图片时保留输入并提示修正。所选预设只作只读上下文，其中的引用会改成普通文字“图片N”，避免被抄进扩写结果；扩写后的引用校验仍只看用户描述。
- 生成时由后端把预设原文直接拼在用户描述前面（预设原文以“。”结尾），再按拼接后的文本校验和转换引用。消息的 `content` 只保存用户描述，预设快照单独存入 `prompt_preset`，会话草稿中的预设存入 `config_prompt_preset`。

`frontend/src/utils/imageMentions.ts` 提供触发识别、编号重排和引用校验。`ImageMentionInput` 使用现有 Ant Design 文本框和弹层，供聊天和历史编辑共用。

后端在 `WorkflowCatalog.validate()` 中验证引用，再由生成适配器使用 `utils/image_mentions.py` 转换：Qwen 使用 `<imageN>`，GPT Image 使用“第N张参考图”。转换仅作用于实际模型调用，保留 `GenerationParameters` 和持久化内容；稀疏输入按实际传入图片顺序映射。旧 `<imageN>` 写法仍支持。提示词扩写必须保留原始引用标记集合，否则返回错误并保留原提示词。

验证覆盖 `frontend/tests/imageMentions.test.ts` 和 `tests/test_image_mentions.py`；浏览器还需检查桌面/手机选图、输入法、刷新、会话切换、历史编辑隔离、删图及生成请求。
