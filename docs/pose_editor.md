# 姿势编辑器与扩展安装引导

`frontend/src/components/PoseEditorWeb.tsx` 在弹窗中通过 iframe 打开 `https://posemy.art/app/?lang=zhHans`。对方当前返回 `Content-Security-Policy: frame-ancestors 'self' https://posemy.art;`，普通浏览器会阻止跨站嵌入。

弹窗提供以下入口：

- **安装扩展**：在新标签页打开 [Ignore X-Frame headers 的 Chrome 商店页面](https://chromewebstore.google.com/detail/ignore-x-frame-headers/gleekbfjekiniecknbkamfmkohkpodhe)。商店的 2.0.0 版本说明支持移除 X-Frame-Options 与 Content-Security-Policy；安装和网站访问权限由用户在 Chrome 中确认。
- **已安装，重新加载**：重建 iframe，并重新检测扩展的实际作用。检测通过后自动隐藏首次使用说明；收起后仍有“安装说明”“重新加载”“直接打开网页”入口。
- **直接打开网页**：关闭弹窗并在新标签页打开姿势编辑器；用户可返回上传或粘贴截图。

扩展会放开网页嵌入限制，引导提示仅在使用姿势工具时启用。安装说明在内嵌网页之外，未确认支持时仍可查看；已启用时默认收起，也可通过“安装说明”手动展开和收起。

## 自动检查

扩展 2.0.0 没有 `externally_connectable` 或公开网页资源查询接口；其 `net_rules.json` 会从所有匹配请求中移除 CSP 和 X-Frame-Options。应用使用需要登录的 `GET /api/service/pose-embedding-check` 返回固定标识、`Content-Security-Policy: frame-ancestors 'none'`、`X-Frame-Options: DENY` 和 `Cache-Control: no-store`。前端使用现有 token 辅助函数发起同源请求，核对标识和浏览器收到的响应头，只有两个限制头都已移除才确认支持。

弹窗打开、重新加载和窗口恢复焦点时检查；每次读取都不使用缓存，四秒超时。未确认时保留说明，不将请求失败或 iframe 的 load 事件当作安装成功，也不把“已安装”状态永久写入浏览器存储。异步结果有先后顺序保护，关闭弹窗后忽略返回值；截图时暂停检查，避免改变裁切区域。从明确未启用变为启用时自动重载 iframe，临时网络失败后的恢复不会重载已经可用的编辑器。

这项检查验证扩展在本站的响应头处理能力，不枚举浏览器插件，也不保证 posemy.art 的独立网站权限、网络或画布初始化已成功；加载异常时可用“安装说明”恢复引导。
